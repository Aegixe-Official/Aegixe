# Optional record templates / 可选核查记录模板

[Back / 返回](../README.md)

These are optional examples for your own records, not AEGIXE products, production APIs, prescribed internal standards or formal audit documents.

以下是供自行记录使用的可选示例，不是 AEGIXE 产品、生产 API、已确认采用的内部标准或正式审计文件。

## screening-record.json

Use verified values and UTC ISO 8601 timestamps. Preserve missing, failed and unsupported checks as unknown. Record issuer restrictions separately from screening results.

用核实过的值填写，时间采用 UTC ISO 8601。缺失、失败或不支持的检查保持未知；发行方限制与风险筛查结果分开记录。

## audit-evidence.md

Record original sources for scope, reviewed version, findings, fixes and deployment. Keep completed client or private payment records in an appropriate internal system, outside this public repository.

记录范围、审阅版本、发现、修复和部署的原始依据。填写后的客户材料或私人支付记录应保存在合适的内部系统，不提交到公开仓库。
